Dynamic threshold derivation — per house, from data
flowchart TD
    A([WM power series\nall 1-min readings]) --> B[Filter: keep readings > 5 W\nremove true-off zeros]
    B --> C[Compute percentiles\nof active distribution]
    C --> D[p05 = 5th percentile\ntypically drain pump level\n50–80 W]
    C --> E[p20 = 20th percentile\nminimum agitation level\n100–200 W]
    D --> F[OFF threshold\n= max p05 × 0.6 , 25W\nround to 5 W]
    E --> G[ON threshold\n= max p20 rounded to 10W , 60W]
    F --> H{Enough data?\n≥ 200 active readings}
    G --> H
    H -->|No| I[Fallback\nON = 100 W\nOFF = 50 W]
    H -->|Yes| J([House-specific\nON thresh + OFF thresh])
    I --> J

Hysteresis state machine — full cycle detection logic
stateDiagram-v2
    [*] --> IDLE
    IDLE --> CONFIRMING : any reading ≥ on_thresh
    CONFIRMING --> IDLE : streak broken\nbefore 3 min
    CONFIRMING --> ACTIVE : on_thresh sustained\nfor ≥ 3 consecutive min\n→ cycle START recorded

    ACTIVE --> ACTIVE : power ≥ off_thresh\n(including drain pump ~50–80W)
    ACTIVE --> DRAINING : power < off_thresh\nlow_streak counter starts

    DRAINING --> ACTIVE : power returns ≥ off_thresh\nbefore 5-min patience\nlow_streak reset

    DRAINING --> VALIDATE : power < off_thresh\nfor 5 consecutive min\n→ cycle END recorded

    VALIDATE --> CYCLE_OK : 15 min ≤ duration ≤ 180 min
    VALIDATE --> DISCARD : duration outside bounds\n< 15 min or > 180 min

    CYCLE_OK --> IDLE : record cycle\nextract energy · peak · heat_mins
    DISCARD --> IDLE
Cycle classification — hot vs cold wash
flowchart LR
    A([Detected cycle]) --> B{Any 1-min bin\n≥ 1 800 W\nfor ≥ 3 min?}
    B -->|Yes| C[HOT WASH\nheating element active\n40–60°C programme]
    B -->|No| D[COLD / WARM WASH\nmotor only · no heating\nor 30°C programme]

    C --> E[Extract\nheat_mins · heat_energy_wh\nhot_wash = True]
    D --> F[Extract\nhot_wash = False]

    E --> G[Energy saving =\nhot_median − cold_median\nper house]
    F --> G

Threshold rationale — grounded in 2013–2015 UK market
flowchart LR
    R1[Min cycle 15 min] --> E1[Shortest quick-wash sold\nin UK 2013–2015\nBosch SpeedPerfect\nCandy · Samsung]
    R2[Max cycle 180 min] --> E2[No domestic programme\nexceeds 3 hours]
    R3[Heat threshold 1 800 W] --> E3[UK front-loader heating element\nrated 1.8–2.5 kW\nbelow = motor only]
    R4[ON streak 3 min] --> E4[Avoids spike noise\ntriggering a cycle\n1–2 min transients ignored]
    R5[OFF patience 5 min] --> E5[Bridges drain phase\ntypically 2–4 min\n5 min gives safety margin]
